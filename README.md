# Casa al Metro

Investigación personal para comprar un departamento en Santiago con **subsidio DS19**, priorizando cercanía al metro, estacionamiento y tipologías de 2+ dormitorios.

## Perfil de búsqueda

- Sueldo: $1.850.000
- RSH: tramo 80–90%
- Meta: mudanza el próximo año
- Must-have: DS19, +1 dormitorio (ideal 2 baños), estacionamiento, barrio tranquilo cerca de metro
- Evitar como 1ª opción: Buin / zonas muy apartadas del centro

## Cómo correr

```bash
npm install
npm run dev -- --port 43127
```

Abre [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Qué incluye la app

- Chequeo de elegibilidad DS19 (RSH, ahorro, topes de ingreso Tramo 2/3)
- Ranking de proyectos inmobiliarios DS19 en Santiago filtrado por tus criterios
- Estimación ilustrativa de dividendo tras subsidio
- Shortlist para visitas a sala de ventas
- Ruta de acción hacia la mudanza del próximo año

## Fuentes

Los datos de proyectos se basan en fichas públicas (MINVU, Maestra, Ciclos, Ingevec, Los Silos, UsaTuSubsidio, Enlace Inmobiliario). **Cupos, precios y tipologías cambian**: confirma siempre en sala de ventas y SERVIU/MINVU.
